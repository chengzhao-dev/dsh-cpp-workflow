# 教学代码的写法

教学代码首先为读者服务：短、完整、能运行、只展示当前概念。工程规则仍以 `developing-cpp` 为准，本文件只写教学场景的取舍。

## 命名

- 类型、函数、枚举用 PascalCase；变量、参数用 snake_case；成员加尾下划线。
- 示例里的名字要表达领域含义，不用 `foo`、`bar`、`data1`：

```cpp
struct Student {
  std::string name;
  int score{0};
};

int AverageScore(const std::vector<Student>& students);
```

- 单个示例里不混用多种命名风格；不要为了“贴近标准库”把变量写成 `Value`。
- 概念名首次出现时用正文解释，不靠名字自解释；`kMaxRows` 比 `MAX` 清楚。

## 初始化

- 默认花括号：`int count{};`、`std::vector<int> values{1, 2, 3};`。
- 需要展示拷贝初始化或类型推导时用 `=`：`std::string name = "demo";`、`auto total = 0.0;`。
- 讲窄化时给对比例：`int x{3.5}` 编译失败，`int x = 3.5` 静默截断。
- 讲容器时明确 `vector<int>(3)` 与 `vector<int>{3}` 的区别；这是常见误解。
- 类成员在声明处给默认值：`int count_{0};`、`std::array<Mark, 9> cells_{};`。

## 枚举行尾注释

需要给枚举值加说明时，整组统一写，语义结果在前：

```cpp
enum class Status : std::uint8_t {
  kInProgress,  ///< 对局继续
  kFirstWins,   ///< 先手获胜
  kSecondWins,  ///< 后手获胜
  kDraw,        ///< 平局
};
```

- 要么全写，要么全不写；只给一半加注释会让读者以为另一半不重要。
- 注释对齐；`///<` 用于成员/枚举值的行尾文档。
- 注释写“这个值表示什么”，不写“这里设置状态”。

## 注释

- 文件头只写标题、读者任务、前置；不超过 6 行。
- 示例上方一句话说明“这个例子演示什么”，不写“下面是代码”。
- 行内注释只解释“为什么”，不翻译代码；`++i;  // 自增` 是噪声。
- 错误示例用 `// 错误：...` 标出，并在正文给真实报错。
- 不写“注意”“重要”而不说注意什么；直接写后果。

## 代码块与省略

- 完整示例有 `int main()`；片段第一行 `// 片段`。
- 片段里省略的类型/函数要说明来源，例如“假设 `Student` 已定义”。
- 不用 `...` 代替关键逻辑；只省略重复的初始化或输出。
- 一个代码块只演示一个点；对比用两个块，标“写法 A / 写法 B”。
- 代码块里不塞构建命令；命令单独一个 shell 块。

## 错误示例

```cpp
// 错误：下标越界是未定义行为，不保证抛异常
int value = values[values.size()];
```

- 明确写“错误”或“不要这样写”；不要和正确写法混在同一块。
- 给真实编译器/运行结果；不能稳定复现的未定义行为，说明“可能崩溃、可能读到垃圾值”。
- 错误示例不加入自动验证的“全部通过”集合；脚本要能跳过并单独检查标记。

## 包含与依赖

- 示例只包含用到的标准头；不要用“万能头”。
- 先包含自己的头，再标准库头；教学单文件示例直接包含 `<iostream>`、`<vector>` 等。
- 不依赖 `using namespace std;`；正文里写 `std::`，让读者知道名字来自哪里。
- 多文件示例的公共头自包含；`main.cpp` 只做组装。

## 输出

- 用 `std::cout` / `std::cerr` + `std::format`；不写 `std::print`（C++23）。
- 输出行加简短标签，让读者知道哪一行对应哪个对象。
- 不在示例里输出大段调试信息；需要时用 `std::cerr` 并说明。
- 浮点输出给固定精度，避免不同实现显示不同位数。

## 长度与节奏

- 单块不超过 40 行；超过时拆成“声明 / 实现 / 调用”。
- 一段正文不超过 5 行连续文字；长解释拆成列表或小标题。
- 每节至少一个可运行例子；纯语法节也要有最小示例。
- 练习代码给骨架，不直接给完整答案；答案放章末。

## 检查清单

- [ ] 命名统一，示例名有领域含义。
- [ ] 初始化方式一致，窄化和容器括号差异讲清。
- [ ] 枚举注释全写或全不写。
- [ ] 注释解释为什么，不翻译代码。
- [ ] 片段有标记，完整示例有 `main`。
- [ ] 错误示例明确标错，报错真实。
- [ ] 只包含用到的头，不用 `using namespace std;`。
- [ ] 输出用 `std::format` + 流，没有 `std::print`。
