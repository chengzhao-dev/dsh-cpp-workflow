# 语言基础的章节顺序

顺序按“读者能写出什么”排，不按语言标准的章节排。每个新概念只依赖前面已经能运行的东西。

## 第一部分：能写一个程序

1. **第一个程序**：`main`、`std::cout`、`return 0`、编译与运行命令。
2. **变量与类型**：`int`、`double`、`bool`、`char`；声明、赋值、作用域。
3. **输入与输出**：`std::cin`、`std::cout`、`std::cerr`；格式化输出用 `std::format`。
4. **表达式与运算符**：算术、比较、逻辑、优先级；整数除法与浮点除法。
5. **条件与循环**：`if` / `else`、`switch`、`for`、`while`、`break` / `continue`。
6. **函数**：参数、返回值、声明与定义、作用域、按值传递。

这一部分结束时，读者能写一个几十行的命令行程序，不涉及指针和类。

## 第二部分：能组织数据

7. **`std::string`**：拼接、查找、长度、按行读取。
8. **`std::vector`**：下标、`size`、范围 `for`、`push_back`、`reserve`。
9. **`std::array`**：固定长度、编译期大小、与 `vector` 的选择。
10. **引用与指针**：别名、地址、空指针、`const` 引用；先讲“为什么需要”，再讲语法。
11. **结构体**：聚合、成员访问、按值/按引用传递。
12. **枚举**：`enum class`、封闭取值、底层类型、与整数的转换。

这一部分结束时，读者能用容器和结构体表达一张表、一条记录。

## 第三部分：能封装行为

13. **类与对象**：数据成员、成员函数、访问控制、构造函数。
14. **不变量与封装**：私有数据、`const` 成员函数、`explicit`。
15. **RAII 与智能指针**：所有权、`unique_ptr`、`shared_ptr`、`weak_ptr`；不写裸 `new` / `delete`。
16. **拷贝与移动**：拷贝构造、移动构造、`std::move`、RVO；先讲行为，再讲规则。
17. **运算符重载**：只重载语义自然的运算符；比较、输出、算术。
18. **继承与多态**：虚函数、override、虚析构；组合优先于继承。

这一部分结束时，读者能写一个带不变量的小类，并解释对象何时构造、拷贝、移动、销毁。

## 第四部分：能用标准库

19. **容器选择**：`vector`、`deque`、`map`、`unordered_map`、`set`；访问模式决定选择。
20. **迭代器与算法**：半开区间、`find` / `sort` / `transform`、范围 `for`。
21. **`std::string_view` 与 `std::span`**：视图不拥有、生命周期、C++20 边界。
22. **`std::optional` / `std::variant`**：可缺失值、多态值；C++20 没有 `std::expected`。
23. **`std::format`**：格式串、对齐、数值格式；输出仍走流。
24. **错误处理**：返回值、异常、合同违反；`main` 边界捕获。

这一部分结束时，读者能选容器、用算法、写可读的错误处理。

## 第五部分：能构建与调试

25. **预处理、编译、链接**：头文件、声明/定义、目标文件、链接错误。
26. **CMake 最小工程**：`cmake_minimum_required`、`project`、`add_executable`、`target_compile_features`。
27. **多文件工程**：`include/`、`src/`、公共头、`target_include_directories`。
28. **库与程序**：静态库、共享库、`target_link_libraries`、RPATH。
29. **测试**：断言、单元测试、`ctest`；先测规则，再测输出。
30. **调试与工具**：编译器警告、clang-format、clang-tidy、ASan/UBSan、调试器。

## 第六部分：进阶主题

31. **模板基础**：函数模板、类模板、推导、头文件定义。
32. **C++20 概念**：`concept`、`requires`、约束错误。
33. **Lambda 与函数对象**：捕获、`std::function`、算法谓词。
34. **并发入门**：`std::thread`、`mutex`、`lock_guard`、数据竞争；只讲最小可用集。
35. **文件与 `std::filesystem`**：路径、读写、错误检查。
36. **性能基础**：复杂度、缓存、测量、ASan/UBSan。

进阶主题按项目需要选讲，不必全部覆盖。

## 页面边界

- **类型页**只讲 `int` / `double` / `bool` / `char` 的表示和常见陷阱；固定宽度、`size_t`、数值安全放到“类型安全”专页。
- **初始化页**讲 `{}`、`=`、`()` 的区别和窄化；`auto` 单独一页或一节，避免混在一起。
- **`const` 页**讲 `const` 变量、`const` 参数、`const` 成员函数；`constexpr` / `consteval` / `constinit` 单独一页。
- **指针页**讲地址、空指针、悬空、所有权之前；智能指针放 RAII 页。
- **类页**讲封装和不变量；继承放后面，避免初学就用继承。
- **异常页**讲“何时抛、何时返回”，不展开异常安全等级；后者放进阶。

## 源文件布局

- 每个部分一个目录，页面文件平铺；不要为每页建子目录。
- 页面文件名用 kebab-case，和标题对应；不要用 `01-` 前缀排序，顺序由目录文件维护。
- 代码示例放 `code/<部分>/<页面>.cpp`，能独立编译；需要多文件的示例单独一个目录。
- 章节正文不复制整份代码；关键片段 inline，完整文件链接到代码目录。

- [ ] 继承在组合之后，模板在类和容器之后。
- [ ] 页面边界清楚，一个页面只解决一个任务。
