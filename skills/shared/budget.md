# 加载预算

三份 `SKILL.md` 共用这一页的预算与层表；技能正文只留入口，不复制本页条文。

## 预算

- 只开当前步对应的一个步骤文件；同一改动域内不同时展开两个技能的步骤。
- 条文只开该步点名的一份；同号案例留到下一次激活。
- 标准档只打开项目技能声明的那一档，没有声明时用本技能已有的新工程默认，不把其余标准档读进来。
- 上限：`SKILL.md` 不超过 100 行；单份 reference 不超过 240 行；一次只开一份；`references/index.md` 不超过 240 行。

## 层与加载

| 层 | 职责 | 何时加载 |
| --- | --- | --- |
| 常驻元数据 | `name`、`description` | 会话目录常驻；正文不加载 |
| 技能正文 | `SKILL.md` 的适用场景、操作、步骤、入口表、完成判据 | 技能被选中时 |
| 步骤 | `steps/0N-*.md` 的当前步骤流程 | 进入该步时只开同号一份 |
| 条文与案例 | `references/` 的规则、案例与术语 | 入口表或步骤点名时；判不准、冲突或排错时按需 |
