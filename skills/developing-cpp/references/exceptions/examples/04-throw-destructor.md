# 正反例：析构

**差**：

```cpp
~Writer() {
    if (file_) file_->Flush();  // 失败时抛？析构中抛会终止程序
}
```

**好**：

```cpp
~Writer() {
    if (file_) {
        try {
            file_->Flush();
        } catch (...) {
            // 析构不抛：失败由显式 Close() 报告的路径处理。
        }
    }
}
```

需要报告关闭失败时，提供显式 `Close()` 返回结果，析构只做兜底。
