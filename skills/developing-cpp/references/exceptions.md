# 异常与错误

本技能对 Google「不使用异常」做书面偏离：**异常可用，但只用于合同违反和程序边界**。可预期的失败用返回值表达。这样既保留 C++ 的清晰错误路径，又不让异常成为控制流。

## 抛还是返回

| 情形 | 做法 | 例子 |
| --- | --- | --- |
| 用户输入非法、文件不存在、解析失败 | 返回结果类型 / `bool` / `std::optional` | `TryParse()` → `ParseResult` |
| 查询越界、构造参数不满足 invariant | 抛合同异常 | `GetTaskState(TaskId)` 越界抛 `std::out_of_range` |
| 程序入口、CLI、工具边界 | 捕获 `std::exception`，打印并返回非零 | `main()` 捕获后 `std::format("错误: {}", e.what())` |
| 内存不足、系统调用失败 | 让标准异常传播，或转成结果类型；不要吞掉 | `std::bad_alloc` 不捕获 |
| 析构函数 | 不抛；失败只记录或忽略 | `~File()` 不抛 |
| 可恢复的业务失败 | 不抛；用结果类型让调用方分支 | `ReserveResult::kOccupied` |

判断句：**调用方能否在不看实现的情况下合理避免？** 能避免的是合同违反（抛）；不能避免的是可预期失败（返回）。

## 合同异常

- 在声明注释里写清：什么条件抛、抛什么类型、调用方应如何避免。
- 类型选择：参数非法 `std::invalid_argument`；越界 `std::out_of_range`；状态不允许 `std::logic_error`；资源失败用标准库已有类型。
- 异常消息用 `std::format` 组合，包含操作、关键值和期望范围：

```cpp
throw std::out_of_range{
    std::format("GetTaskState: id={} 超出 [0, {})", id, kTaskCount)};
```

- 不要抛裸 `std::string`、`const char*` 或自定义无继承的类型；从 `std::exception` 派生时实现 `what()`。
- 不要用异常做正常分支；循环里用异常控制流程视为缺陷。

## 捕获

- 按 `const` 引用捕获：`catch (const std::exception& error)`。
- 只捕获能处理的类型；不认识的异常继续抛，不要 `catch (...)` 后静默返回。
- 捕获后要么恢复成有效状态，要么返回错误；不要带着半初始化对象继续运行。
- `noexcept` 只写在确实不抛的函数上；析构函数、移动操作默认不抛，除非有明确理由。

## 程序边界

`main()` 是异常边界：库让合同异常向上传播，入口统一翻译成用户可读的消息和非零退出码。

```cpp
int main() {
  try {
    return Run(std::cin, std::cout);
  } catch (const std::exception& error) {
    std::cerr << std::format("错误: {}\n", error.what());
    return 1;
  }
}
```

- 消息面向用户，不打印栈、不暴露内部路径；调试信息写日志或测试输出。
- 退出码：成功 `0`；可预期失败 `1`；用法错误可以用 `2`。同一个程序保持一致。
- 不要在每个函数里 `try/catch` 后打印；让异常走到边界，中间层只在能补偿时捕获。

## 消息文案与日志

异常消息是给调用者和用户看的诊断，不是日志流：

- 格式固定为 `<ApiName>: <主体> <原因>`，例如 `GetTaskState: id=3 超出 [0, 3)`。
- 写操作名和关键值，不写「出错了」「非法」这类没有信息量的词。
- 不引入日志框架，不在库代码里打印；需要诊断上下文时由边界层记录，异常本身只携带消息。
- 同一条消息在测试里断言稳定的前缀，不断言完整路径或平台相关文本。

## 与 `std::format` 的关系

- 异常消息、用户提示、测试断言消息优先 `std::format`。
- C++20 没有 `std::print`；格式化后写入流。
- 格式串里的类型要匹配；不要把用户输入直接拼进格式串（格式串必须是可信字面量）。

## 检查清单

- [ ] 可预期失败没有用异常。
- [ ] 捕获按 `const` 引用，未吞掉未知异常。
- [ ] 析构函数不抛。
- [ ] 入口有统一捕获，消息用 `std::format`，退出码一致。
