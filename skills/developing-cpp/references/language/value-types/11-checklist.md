# 检查清单

- [ ] 参与协议、布局或跨平台边界的整数有明确宽度（`01-width.md`）。
- [ ] 业务编号与容器下标没有混用有符号和无符号（`02-signed.md`）。
- [ ] 封闭状态集合用 `enum class`，没有裸整数状态码（`04-enum.md`）。
- [ ] 没有第二种原因的缺失用 `std::optional`，不用哨兵枚举项（`04-enum.md`）。
- [ ] 查询成员标了尾部 `const`；`[[nodiscard]]` 只出现在结果型 API，结果都有分支处理（`06-const-method.md`、`07-nodiscard.md`）。
- [ ] 下标访问前有边界证明，或使用 `at`；乘加得到下标前先拓宽各操作数。容器、字符串与 `span` 的访问同样适用（`09-subscript.md`）。
- [ ] 浮点比较有容差，金额没有用 `double` 结算（`10-float-bool.md`）。
