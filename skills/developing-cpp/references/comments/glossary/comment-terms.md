# 注释术语与用词

本文件是 `references/comments/comment-rules.md` 与 `comment-style.md` 的附录，只在判不准用词、改写类型注释或核对书稿摘录时打开；它不随这两份一起加载，也不重复句式、位置和长度规则。

## 一条概念只认一个词

| 概念 | 首选 | 避免 | 说明 |
| --- | --- | --- | --- |
| `Position` 类型 | 行列坐标 | 位置类型、坐标点、有序数对 | 类型名保持 `Position`，参数名用 `pos` |
| 棋盘上的点 | 位置 | 坐标点、方格坐标 | 说语义位置时用「位置」 |
| `Square` | 方格 | 单元、格子、棋子 | 「棋子」只指对局中的实体棋子 |
| `Board` | 棋盘 | 盘面、棋局 | 「棋局」只指一局对局 |
| `SquareValue` 类型 | 方格的值 | 值类型、方格状态、状态枚举 | 类型注释写「方格的值。」 |
| `SquareValue` 的取值 | 空、X、O | 状态为空、尚未设置、状态为 X | 行尾写「空」「X」「O」；「空」也用于指没有值的方格本身 |
| `Place` 的动作 | 落子 | 放置、更新状态、写入 | `Game::Place` 执行一手；`Board::SetSquare` 只写入，不叫落子 |
| `PlaceResult` 类型 | 一次落子的结果 | 放置结果、落子结果、方格状态变更结果 | 类型注释写「一次落子的结果。」；由 `Game` 产生 |
| `PlaceResult` 的取值 | `kPlaced`、`kInvalidPlayer`、`kFinishedGame`、`kEmptySquare`、`kOccupiedSquare` | 成功、失败、写入成功、落子失败 | 行尾写「成功：…」「失败：…」；成功排第一，其余按固定顺序；玩家不对是 `kInvalidPlayer`，终局是 `kFinishedGame`，空值是 `kEmptySquare`，占用是 `kOccupiedSquare` |
| `GameResult` 类型 | 对局结果 | 对局状态、棋局结果、GameState | 类型注释写「对局结果。」 |
| `GameResult` 的取值 | 对局进行中、X 已获胜、O 已获胜、平局 | 未结束、X 赢、O 赢、和棋 | 每行以「对局」或胜负主体开头，写完整状态 |
| `Game::Place` 的动作 | 执行一次落子 | 交给棋盘、落下这一手 | 第一句写「执行一次落子。」，交接与记录由 `@retval` 承担 |
| `GetResult` | 当前对局结果 | 棋盘状态、对局状态 | 第一句写「获取当前对局结果。」 |
| `Player` 类型 | 玩家 | 对局的一方、落子的一方 | 类型注释写「玩家。」，取值由枚举项说明 |
| `Player` 的取值 | 玩家为 X、玩家为 O | 先手、后手、X 方、O 方 | 每行只写「玩家为」加取值，先后手由对局规则说明 |
| `Move` 类型 | 落子记录 | 一次落子、落子 | 类型注释写「落子记录。」，第二段写「记录一次落子，包括落子位置与落子玩家。」 |
| `Move` 的短字段 | 落子位置：棋盘上的行列坐标、落子玩家：游戏中的玩家 | 坐标、玩家 | 行尾写「字段：说明」，冒号后补字段名看不出的语境 |
| `history_` | 落子历史 | 已经下过的落子、每一次落子 | 主注释写「落子历史：按落子先后保存。」，`GetHistory` 写「获取落子历史。」 |
| `Clear` 的动作 | 清空 | 重置为空、清空值、收回 `kEmpty` | `Board::ClearSquare` 清一格；`Board::Clear` 清整盘；单格只 `SetValue` |
| `GetSquare` 的返回 | 方格副本 | 方格、引用 | 按值返回必须说「副本」 |
| 坐标越界 | 坐标越界时抛出 `std::out_of_range` | 检查越界 | 只用于会抛的校验函数 |
| `GetValue` | 当前值 | 状态值、方格的状态 | 返回当前值 |
| `GameResult` | 对局结果 | 棋盘状态、对局状态 | 结果由 `Game` 计算，棋盘不保存状态 |
| `row`、`col` | 行号、列号 | 行、列、第一行、第一列 | 成员注释写「行号，默认值为 0」，不写棋盘语义，类注释不重复 |

## 位置与坐标

- `Position` 是类型名，中文叫「行列坐标」；参数名用 `pos`（`position` 的常见缩写），不写 `Position position`。
- 「棋盘上的一个位置」指语义位置；「一行一列的坐标」指具体值。两者不混成「坐标点」，也不写成「有序数对」。
- 成员注释写「行号，默认值为 0」「列号，默认值为 0」；类型是 `int`，可为负，不写「从 0 起算」；类注释不再重复默认值，否则和成员注释冲突。
- `Position` 是通用坐标，不写「0 表示第一行」「0 表示第一列」这类棋盘语义；哪一行是首行由使用坐标的模块（例如 `Board`）说明。

## 方格与棋盘

- `Square` 只说「方格」；「棋盘上的方格」只在需要强调归属时用，类型注释本身不写棋盘。
- `Board` 只说「棋盘」；`squares_` 说「方格数组」，不写「存储方格的数组」这种复述。
- 「棋子」只指对局中的实体棋子；取值里的 X 或 O 叫「值」，不叫「棋子」。
- `PlaceResult` 的五项先写「成功」或「失败」；冒号后按固定顺序写「落子玩家 → 对局状态 → 写入的值 → 目标方格」，某一项不适用时省略。成功说「落子玩家是当前玩家，值已写入方格」，玩家不对说「落子玩家不是当前玩家，没有写入」，终局说「对局已经结束，没有写入」，空值说「要写入的值是 kEmpty，没有写入」，占用说「目标方格已有值，没有写入」；「没有写入」由类型注释统一交代，不在每一行重复；不说「已有状态」或「占据」。
- 结果枚举与分支注释的完整写法见 `references/naming/identifier-names.md` 与 `references/comments/comment-rules.md`；本表只定词。

## 玩家

- `Player` 的类型注释与枚举项统一用「玩家」：类型写「玩家。」，取值写「玩家为 X」「玩家为 O」，不把先后手这类对局规则写进取值说明。
- 不用「对局的一方」「落子的一方」指 `Player`；「一方」只在对局叙述里说明轮换关系。

## 落子记录

- `Move` 的类型注释写「落子记录。」，第二段写「记录一次落子，包括落子位置与落子玩家。」；不写「一次落子。」。
- 短字段写「落子位置：棋盘上的行列坐标」「落子玩家：游戏中的玩家」；冒号前是字段名，冒号后补字段名看不出的语境。
- `Move::operator==` 写「相等运算符。」，`@return` 写「位置与玩家都相同时返回 true；不成立时返回 false。」。
- 落子历史的成员写「落子历史：按落子先后保存。」，`GetHistory` 写「获取落子历史。」；不写「已经下过的每一次落子」，把集合摊开成「每一次…」既长，也没点出「历史」这个名词。

## 对局

- `Game::Place` 写「执行一次落子。」；不写「把一次落子交给棋盘；成功时记录这一步」，第一句只写动作，交给棋盘与记录这一步由 `@retval` 承担。
- 固定顺序由 `@retval` 的排列表达，不用 `@note` 复述；终局作为正常结果返回，不靠 `@note` 解释。

## 更新与写入

- `Square::SetValue` 的动作统一写「设值」：`Square::SetValue` 把传入的值写入方格，覆盖原值；`Board::SetSquare` 只检查坐标再写入，不判空值与占用。
- 「放置」不用在任何接口语境：`Board::SetSquare` 说「写入」，`Game::Place` 说「落子」。
- `kPlaced` 说「成功：落子玩家是当前玩家，值已写入方格」；`kInvalidPlayer` 说「失败：落子玩家不是当前玩家，没有写入」；`kFinishedGame` 说「失败：对局已经结束，没有写入」；`kEmptySquare` 说「失败：要写入的值是 kEmpty，没有写入」；`kOccupiedSquare` 说「失败：目标方格已有值，没有写入」。枚举项行尾、`@retval` 与设置预览三处用同一句，三者不互换。
- `Clear` 说「清空」或「清空为 `kEmpty`」，不写「重置为空」「清空值」「删除状态」；`Board::ClearSquare` 说「清空一个方格」，`Board::Clear` 说「清空棋盘」。

## 返回值与副本

- `GetSquare` 按值返回：第一句和 `@return` 都写「方格副本」，不写「该位置的方格」，否则读者会以为拿到引用。
- `GetValue` 返回枚举值，写「当前值」，不写「状态值」。
- `GameResult` 写「对局结果」，不写「状态」；`Board` 没有 `GetStatus`，终局由 `Game::GetResult` 计算。
- 会抛的查询先写抛出条件，再写 `@throws`；`@param` 写「待检查/读取/更新的坐标」，不把「棋盘内」当前置条件。

## 初始状态与特殊成员

- 类有不变量时，类注释拥有初始状态与生命周期；纯值容器的初始状态归默认构造函数，类注释只写这个类型是什么。默认构造函数写具体初始状态，如「初始化为空方格」「初始化为空棋盘」「初始化为空对局」，不写「建立初始状态」。对象由多个成员组成时写整个对象的初始状态，不逐项罗列成员。
- 数据成员只写成员自身：`row`、`col` 写行号/列号与默认值；`value_` 写「方格的值」，不重复类注释的初始值。
- 文件头只写 `@file`、`@brief` 与文件组成；不写作者、版权年份、变更史。

## 依据

- [Google 中文 C++ 风格指南·注释](https://zh-google-styleguide.readthedocs.io/en/stable/google-cpp-styleguide/comments.html)：类讲用途，函数讲输入输出，不翻译代码。
