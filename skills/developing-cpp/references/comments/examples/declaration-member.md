# 正反例：数据成员

**差**：

```cpp
Board board_;  // 对局棋盘。
std::array<Square, kSquareCount> squares_{};  // 存储棋盘方格。
```

前一句把名字翻译了一遍；后一句只复述声明，没有说清下标怎样换算成行列。

**好**：

```cpp
/// 方格数组：按行优先排列。
std::array<Square, kSquareCount> squares_{};
/// 当前玩家：开局由 X 玩家落子。
Player current_player_{Player::kX};
/// 落子历史：按落子先后保存。
std::vector<Move> history_;
```

主注释写在声明上一行，类数据成员（含私有）统一用 `///`；第一句先说是哪个成员，再用全角冒号补名字和类型看不出、只属于该成员的范围、轴向、哨兵与所有权。类级初值与状态迁移写在类注释，成员注释不重复。行尾不写补充；`///<` 只给枚举项和 `struct` 短字段。名字已经说明存放对象的 `board_` 不写「对局棋盘」。`struct` 短字段的行尾注释只写字段自身：`Position` 写「行号，默认值为 0」「列号，默认值为 0」，不写「0 表示第一行」这类棋盘语义；哪一行是首行由使用坐标的模块说明。
