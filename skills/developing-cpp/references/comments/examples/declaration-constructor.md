# 正反例：构造函数与析构函数：标签 + 职责

**差**：

```cpp
/// 构造函数：创建一个空棋盘。
Board() = default;
```

「创建」复述了声明，读者仍不知道构造完成后棋盘里是什么、`squares_` 的每个元素是否已经有值。

**好**：

```cpp
/// 默认构造函数：初始化为空棋盘。
Board() = default;

/// 析构函数：保证通过接口指针正确删除派生类对象。
virtual ~Ai();
```

`= default` 本身不说明成员被初始化成什么；`squares_{}` 把每个 `Square` 初始化成空方格，这条后置条件从签名上看不出来。标签说明这是哪一类特殊成员，冒号后写它建立的状态或承担的职责。
