# 正反例：布尔查询写主体是否状态

完整写法：

```cpp
/// 指定坐标上的棋盘方格是否为空。
///
/// @param pos 棋盘上的行列坐标。
///
/// @return 坐标在棋盘内且该格为空时返回 true；越界或该格是 X 或 O 时返回 false。
[[nodiscard]] bool IsSquareEmpty(Position pos) const;
```

布尔查询的第一句写「主体是否状态」，句中有「是否」，句首不用「检查」「判断」「校验」「验证」；`@return` 写成立与不成立的条件；能力边界不写成否定清单，调用方要满足的条件用正向限定或 `@pre`。
