# 性能与常见陷阱

先证明慢在哪里，再改代码。没有测量的“优化”通常只是把复杂度搬了个位置。

## 测量顺序

1. 写清可观察的性能目标：延迟、吞吐、内存上限，或“输入规模翻倍时耗时如何增长”。
2. 用真实规模的输入测量；玩具数据上的常数差异没有意义。
3. 先看算法复杂度，再看内存访问，再看常数因子。
4. 用 profiler 找热点；不要凭代码长短猜。
5. 改一处，复测同一指标；记录测量条件和结果。

- 发布构建（`-O2` / `-O3`）测性能，调试构建测正确性。
- 微基准要防止编译器把结果优化掉；使用输入、累加结果并输出。
- 单次测量受缓存、频率、调度影响；取多次的中位数或分位数，不只报最好的一次。

## 复杂度与数据结构

- 先问操作的渐进复杂度：`vector` 尾部追加摊还 O(1)，中间插入 O(n)；`map` 查找 O(log n)；`unordered_map` 平均 O(1)、最坏 O(n)。
- 嵌套循环里做线性查找通常是把 O(n) 变成 O(n²)；先建索引或排序。
- 频繁按 key 查找时，`unordered_map` 通常比 `map` 快，但迭代顺序不稳定；需要有序输出时不要选它。
- 小规模数据（几十个元素）上，连续 `vector` 的线性扫描常比哈希表更快；不要机械套用复杂度。
- 递归深度可能随输入增长时，改成迭代或显式栈；栈溢出不是可捕获的异常。

## 内存与缓存

- 连续存储对缓存友好；`vector<struct>` 比 `vector<unique_ptr<struct>>` 更容易预取。
- 只遍历部分字段时，AoS（数组的结构）可能浪费带宽；数据量大且按列访问时考虑 SoA（结构的数组），但先用 profiler 证明。
- 小对象按值传递通常比堆分配快；不要为了“避免拷贝”给所有参数加指针。
- `reserve` 减少 `vector` 扩容和搬移；只有已知上界或能准确估算时才用。
- 移动大对象比拷贝便宜，但移动不是免费；不要把 `std::move` 当成优化开关。
- 返回局部对象直接 `return value;`，依赖 RVO / NRVO；`return std::move(value);` 会阻止优化。

## 未定义行为与安全

以下行为没有标准结果，优化后可能表现为“有时对”：

- 数组/容器越界访问（`operator[]`、指针算术）。
- 解引用空指针或已释放对象（use-after-free、double free）。
- 读取未初始化变量。
- 有符号整数溢出。
- 数据竞争：多个线程无同步地读写同一对象。
- 用 `reinterpret_cast` 把对象当无关类型访问，违反严格别名规则。
- 对象生存期结束后继续使用指针或引用。

工具：

- AddressSanitizer（ASan）查越界、use-after-free、double free。
- UndefinedBehaviorSanitizer（UBSan）查有符号溢出、空指针、对齐等问题。
- ThreadSanitizer（TSan）查数据竞争。
- `-Wall -Wextra -Wpedantic` 打开常用警告；不要靠关闭警告“修复”问题。

ASan/UBSan 有运行期开销，只在测试和排查时开；发布构建仍要保留编译器警告。

## 常见性能陷阱

| 现象 | 常见原因 | 先做什么 |
| --- | --- | --- |
| 循环里反复分配 | 每次迭代构造容器/字符串 | 移到循环外，或 `reserve` |
| 大量拷贝 | 范围 `for` 按值、参数按值传大对象 | 改 `const&`，确认所有权 |
| 哈希表慢 | 哈希冲突、频繁 rehash | 预留桶数，检查哈希质量 |
| 字符串拼接慢 | 反复 `+` 产生临时对象 | `reserve` + `+=`，或 `std::format` 一次成型 |
| 多线程没有变快 | 锁竞争、伪共享 | 缩小临界区，按缓存行对齐 |
| 递归慢/栈溢出 | 重复子问题、深度大 | 记忆化或改迭代 |
| 输出慢 | 每行 flush、频繁 `std::endl` | 用 `'\n'`，需要时再 flush |

## 不要做的“优化”

- 不要用全局可变状态换速度；正确性和可测试性先于常数因子。
- 不要为未测量的热点写复杂的手工内存管理。
- 不要用 `reinterpret_cast` 绕过类型系统；需要二进制布局时用 `std::bit_cast` 并确认可平凡复制。
- 不要关闭整类 clang-tidy 检查来让构建通过；修代码或局部 `NOLINT` 并写理由。
- 不要把 `std::endl` 当换行符；它每次都会 flush。

## 检查清单

- [ ] 性能目标可测量，测量条件已记录。
- [ ] 先看复杂度，再看缓存，再看常数。
- [ ] 没有未测量的“优化”。
- [ ] 大对象传递和返回没有多余拷贝。
- [ ] ASan/UBSan 在测试中跑过，警告没有被关闭。
- [ ] 没有用未定义行为换速度。
