# 注释术语与用词

本文件是 `source/07-comments/01-comment-rules.md` 的附录，只在判不准用词、改写类型注释或核对书稿摘录时打开；它不随 `source/07-comments/01-comment-rules.md` 一起加载，也不重复句式、位置和长度规则。

## 一条概念只认一个词

| 概念 | 首选 | 避免 | 说明 |
| --- | --- | --- | --- |
| `Position` 类型 | 行列坐标 | 位置类型、坐标点、有序数对 | 类型名保持 `Position`，参数名用 `pos` |
| 棋盘上的点 | 位置 | 坐标点、格子坐标 | 说语义位置时用「位置」 |
| `Cell` | 格子 | 单元、方格、棋子 | 「棋子」只指对局中的 X 或 O |
| `Board` | 棋盘 | 盘面、棋局 | 「棋局」只指一局对局 |
| `CellState` 类型 | 格子状态 | 格子的状态、格子状态值 | 类型注释写「格子状态。」 |
| `CellState` 的取值 | 格子为空、格子为 X、格子为 O | 状态为空、尚未设置、状态为 X | 每行都以「格子」开头，写完整状态 |
| `Place` 的动作 | 放置 | 更新状态、写入格子、落子 | `Cell::Place` 放置一格；`Board::Place` 把取值转给对应格子 |
| `PlaceResult` 类型 | 放置结果 | 格子状态变更结果、格子的变更结果 | 类型注释写「放置结果。」 |
| `PlaceResult` 的取值 | 主体 + 状态：kRejected、kOccupied、kUpdated | kNoInput、kEmptyInput | 每个取值两个词以内，失败写原因、成功写结果，不重复 Rejected |
| `MoveResult` 类型 | 一次落子的结果 | 落子结果、放置结果 | 类型注释写「一次落子的结果。」 |
| `MoveResult` 的取值 | 落子失败/成功：原因 | 已落子、未落子、成功、失败 | 先写主体与结果，再写原因 |
| `BoardState` 类型 | 棋盘状态 | 对局结果、棋盘的结果、棋局状态 | 类型注释写「棋盘状态。」 |
| `BoardState` 的取值 | 棋盘尚未分出胜负、棋盘上 X 已连成一线、棋盘上 O 已连成一线、棋盘已满且无人连成一线 | 尚未结束、X 成线、O 成线、棋盘已满 | 每行都以「棋盘」开头，写完整状态 |
| `Player` 类型 | 玩家 | 对局的一方、落子的一方 | 类型注释写「玩家。」，取值由枚举项说明 |
| `Player` 的取值 | 玩家为 X：先手、玩家为 O：后手 | 先手、后手、X 方、O 方 | 每行以「玩家为」开头，再补先后手 |
| `Clear` 的动作 | 清空 | 重置为空、清空值、收回 `kEmpty` | `Cell::Clear` 清空格子；`Board::Clear` 逐格清空 |
| `GetCell` 的返回 | 格子副本 | 格子、引用 | 按值返回必须说「副本」 |
| 坐标越界 | 坐标越界时抛出 `std::out_of_range` | 检查越界 | 只用于会抛的校验函数 |
| `GetState` | 当前状态 | 现在的结果、最新结果 | 状态是棋盘的快照 |
| `row`、`col` | 行号、列号 | 行、列 | 成员注释写「默认值为 0」，类注释不重复 |

## 位置与坐标

- `Position` 是类型名，中文叫「行列坐标」；参数名用 `pos`（`position` 的常见缩写），不写 `Position position`。
- 「棋盘上的一个位置」指语义位置；「一行一列的坐标」指具体值。两者不混成「坐标点」，也不写成「有序数对」。
- 成员注释写「行号，默认值为 0」「列号，默认值为 0」；类型是 `int`，可为负，不写「从 0 起算」；类注释不再重复默认值，否则和成员注释冲突。

## 格子与棋盘

- `Cell` 只说「格子」；「棋盘上的格子」只在需要强调归属时用，类型注释本身不写棋盘。
- `Board` 只说「棋盘」；`cells_` 说「格子数组」，不写「存储格子的数组」这种复述。
- 「棋子」只指对局中的 X 或 O；格子的内部值叫「状态」，不叫「棋子」。
- `PlaceResult` 的三种结果说「格子状态已变更」「格子状态未变更」，不说「成功」「失败」；拒绝覆盖说「格子是 X 或 O」，不说「已有状态」或「占据」。
- 结果枚举与分支注释的完整写法见 `source/06-naming/01-identifier-names.md` 与 `source/07-comments/01-comment-rules.md`；本表只定词。

## 玩家

- `Player` 的类型注释与枚举项统一用「玩家」：类型写「玩家。」，取值写「玩家为 X：先手」「玩家为 O：后手」。
- 不用「对局的一方」「落子的一方」指 `Player`；「一方」只在对局叙述里说明轮换关系。

## 更新与写入

- `Cell::Place` 的动作统一写「放置」：`Cell::Place` 放置一格，`Board::Place` 把一次落子的位置与状态转给对应格子。
- 「写入」只用于数组、文件、流这类输出目标；不写「写入一个格子」「把状态写入格子」。
- 「放置」表示把状态放到空格子；「更新」只用于 `kUpdated` 的结果说明；「格子是 X 或 O」表示拒绝覆盖。三者不互换。
- `Clear` 说「清空」或「清空为 `kEmpty`」，不写「重置为空」「清空值」「删除状态」；`Board::Clear` 说「清空棋盘」，逐格调用 `Cell::Clear`。

## 返回值与副本

- `GetCell` 按值返回：第一句和 `@return` 都写「格子副本」，不写「该位置的格子」，否则读者会以为拿到引用。
- `GetState` 返回枚举值，写「当前状态」，不写「状态值」。
- `GetState` 写「当前状态」，不写「现在的结果」。
- 会抛的查询先写抛出条件，再写 `@throws`；`@param` 写「待检查/读取/更新的坐标」，不把「棋盘内」当前置条件。

## 初始状态与特殊成员

- 类注释拥有初始状态与生命周期；默认构造函数只写「建立初始状态」，不再重复具体状态值。
- 数据成员只写成员自身：`row`、`col` 写行号/列号与默认值；`state_` 写「格子当前的状态」，不重复类注释的初始值。
- 文件头只写 `@file`、`@brief` 与文件组成；不写作者、版权年份、变更史。

## 依据

- [Google 中文 C++ 风格指南·注释](https://zh-google-styleguide.readthedocs.io/en/stable/google-cpp-styleguide/comments.html)：类讲用途，函数讲输入输出，不翻译代码。
- [LeviLamina C++ 风格指南](https://docs.levimc.org/LeviLamina/zh/maintainer_guides/cpp_style_guide/)：类注释至少简介与公开成员，函数注释含参数、返回值与异常。
- [OpenHarmony C++ 语言编程规范·注释](https://www.bookstack.cn/read/openharmony-1.0-zh-cn/contribute-OpenHarmony-cpp-coding-style-guide.md)：按需、简洁、无二义性，不重复代码信息。
