# 正反例：固定坐标用表

**差**：每次判断成线，都用循环把八条线的坐标重新拼一遍；行、列、对角线混在一个循环里，读者要跟着跑两遍才知道哪八条。

```cpp
// 差：用循环现写八条线，坐标藏在控制流里。
std::vector<std::vector<Position>> BuildLines() {
  std::vector<std::vector<Position>> lines;
  for (int row = 0; row < kRows; ++row) { /* ... */ }
  // 列与两条对角线再各写一段
  return lines;
}
```

**好**：固定坐标写成具名命名空间里的 `constexpr` 常量表，`HasLine` 与 `PreviewWin` 共用，所以不放进任何一个函数体；格子用 `at()`，整条线 `all_of`、八条线 `any_of`，函数不标 `noexcept`。

```cpp
// board.cpp 的 namespace tictactoe：行、列、对角线三组，坐标固定。
constexpr std::array<std::array<Position, 3>, 8> kLines = {{
    {{{0, 0}, {0, 1}, {0, 2}}},  // 行 0
    {{{1, 0}, {1, 1}, {1, 2}}},  // 行 1
    {{{2, 0}, {2, 1}, {2, 2}}},  // 行 2
    {{{0, 0}, {1, 0}, {2, 0}}},  // 列 0
    {{{0, 1}, {1, 1}, {2, 1}}},  // 列 1
    {{{0, 2}, {1, 2}, {2, 2}}},  // 列 2
    {{{0, 0}, {1, 1}, {2, 2}}},  // 对角线
    {{{0, 2}, {1, 1}, {2, 0}}},  // 反对角线
}};
```

每个格子要分别处理时仍写 `row` / `col` 循环，例如收集空格、终端打印。
